## ☕ Шаг 1. Обложка для соцсетей (Квадрат 1:1)

**Промпт:** Квадратная обложка для соцсетей для уютной экологичной кофейни «EcoBean Coffee». Стиль: теплый, натуральный, минимализм. В центре: чашка кофе с рисунком в виде листа на пенке, окруженная зернами кофе и многоразовым стаканом. Фон: мягкий размытый фон современной кофейни с растениями. Цвета: землистые тона, оттенки коричневого и зеленого. Без текста.

## 🎨 Шаг 2. Две иллюстрации в едином стиле

**Промпт 1:** Стиль плоской иллюстрации, дружелюбный бариста передает чашку кофе клиенту через стойку. Чашка многоразовая. Сцена теплая и приветливая. Палитра: пастельные цвета, приглушенный коричневый, кремовый, мягкий зеленый. Легкая текстура бумаги.

**Промпт 2:** Стиль плоской иллюстрации, крупный план рук, сажающих саженец кофейного дерева в землю. Символизирует рост и экологичность. Та же палитра: пастельные цвета, приглушенный коричневый, кремовый, мягкий зеленый. Легкая текстура бумаги. Единый стиль с предыдущим изображением.

- **GigaChat (Prompt Ignoring / Mode Collapse):** Модель проигнорировала второй промпт (про посадку саженца). Вместо этого она сгенерировала две слегка отличающиеся вариации первого промпта (два разных бариста). Это классическая проблема удержания длинного контекста в диффузионных моделях.

## 🍬 Шаг 3. Стикеры с персонажем (Стикерпак)

**Промпт:** Создай набор из 6 стикеров (стикерпак) в едином стиле для экологичной кофейни «EcoBean Coffee». Персонаж: милое, дружелюбное кофейное зерно в стиле каваи. У него большие выразительные глаза, улыбка, есть маленькие ручки и ножки. Стиль: Плоская векторная иллюстрация, яркие и чистые цвета, контур, белый фон. Основные цвета: оттенки коричневого, зеленого и кремового. Список стикеров для набора: 1. Приветствие — персонаж машет рукой. 2. Благодарность — персонаж держит сердечко. [и т.д. по заданию]

📉 **Анализ недостатков моделей:**

- **GigaChat:** Явный аутсайдер в этой задаче. Сгенерированные изображения имеют низкое разрешение (заметная пикселизация), а композиция и сюжет стикеров выглядят слабо проработанными по сравнению с конкурентами. Модель плохо справилась с задачей "flat vector illustration" на белом фоне.

⚠️ **Техническое примечание:** Все три модели столкнулись с ограничением мульти-объектной генерации. Вместо 6 отдельных стикеров нейросети сгенерировали 1-2 крупных изображения или попытались объединить действия. Для продакшена стикерпака требуется генерация каждого стикера отдельным запросом с фиксацией `seed`.
